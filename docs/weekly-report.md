# 日报聚合为周报 · V2.1.1

继承 V2.02 的规则，独立模式的周报和来源可在软件内打开。

## 操作

启动卡片，点击右上角“••• → 周报汇总…”。

1. 选择周期内任一天，或点击“本周”“最近一期”。
2. 先点击“预览周报”，查看范围、有效日记数量、原文摘录和保存位置。
3. 点击“生成／更新周报”。已有文件只更新 AUTO 自动区，外部手工补充、YAML 和标题保留。
4. “打开已保存周报”在独立模式使用内置资料库，在 Obsidian 模式使用本机关联应用打开；发生保存错误时预览保留，可重试或另存预览草稿。

首次启动先选择使用 Obsidian 或独立使用。Obsidian 模式选择已有日记库或新建 DailyNote；独立模式创建 Diary 本地资料夹，也可重新载入已有 DiaryCard 资料夹。

## 七天范围

每期固定汇总 **上一周六至本周五**，以截止周五的 ISO 周命名。例如 2026-W44 覆盖 2026-10-24—2026-10-30。

默认输出在当前库的 周报/ISO周年/ISO周年-W周数-工作周报.md，可在周报窗口修改为库内其他独立目录。

按归属日期 journal_date、完整 YYYY-MM-DD 文件名、date 的顺序确定日记日期，只纳入所选日记目录内 type: diary 的 Markdown 文件。自定义日记目录沿用卡片的配置。没有可确认日期的记录不猜测。

## 自动生成时间

在周报窗口勾选“按指定时间自动生成”，选择星期、小时和分钟，再点“保存周报设置”。

- 周一至周日均可选择，范围 00:00—24:00，精确到分钟；24 点只允许 24:00，即次日 00:00。
- 时间采用北京时间（UTC+8），不依赖设备当前显示时区。
- 以最近已到达的生成时点为目标，再取该逻辑生成日当天或之前最近的截止周五。
- 例如：周日 24:00 在周一 00:00 生成刚结束周五那一期；周一至周四的生成时间也处理最近的上一截止周五。周五当天生成会纳入当时已保存的记录。
- 卡片运行（含隐藏至托盘）时约每 15 秒检查；正在输入、保存或处理冲突时会延后。退出期间不运行，下次打开补跑最近一期，不批量补齐所有历史周。
- 自动生成默认关闭，避免与原库已有的 Windows 周报任务重复。原库任务不被安装、注销或改时；不要同时为同一库开启两套自动生成。

设置按日记库单独存储于 data/weekly/。切换库后不会把另一库的定时设置套用过去。周报窗口里的星期与时间不改变每期周六至下周五的范围。

## 整理规则

沿用原库的本地分类摘编：工作成果与证据、有效做法、学习内容、问题与风险、后续计划、参考笔记，有内容时增加其他记录。

已完成任务和未完成待办区分；规划即使已勾选也保留规划语境；可能原因保持待确认。模板提示、空复选框、空表格、HTML 注释、代码围栏中的文本不计作成果。同类相同表述去重，保留多个来源链接。处理全程不调用 AI、不上传、不改原日记。

## 重跑、冲突和边界

自动区为唯一一对 AUTO:START / AUTO:END 注释标记。标记异常时另存“待合并”，不覆盖原件。原文输入未变时不重复重写。

预览后日记改变，会刷新预览并要求再次生成；预览后周报被他处修改，会停止覆盖并保留预览。更新前在 data/weekly/backups 保存旧周报副本。写入失败时尝试恢复原文件，预览仍保留；物理断电不作绝对保证。

生成只读取当时文件现有内容，不能还原周五某个时刻的历史版本。尚未结束的周期会明确提示仅包含目前已保存的内容。
