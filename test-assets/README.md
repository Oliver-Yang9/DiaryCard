# 验证素材

- `motion.gif`：本项目为 GIF 循环与暂停验证生成的示例动画，不含私人图片。
- `flower.mp4`：[MDN video 文档](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video) 使用的视频示例；下载源为 https://developer.mozilla.org/shared-assets/videos/flower.mp4 。仅用于本机 MP4 解码、暂停、循环与恢复测试，不是程序默认背景。

验证过程只读取这些本机素材；程序本身不下载背景文件，不上传日记。
