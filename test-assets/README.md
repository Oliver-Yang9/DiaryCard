# 验收素材

motion.gif 为本项目生成的示例循环动画；review-assets/sample-background.png 为本项目生成的示例背景，不含私人图片。程序图标由 src/Program.cs 生成。

MP4 播放验收使用 MDN video 文档的 flower.mp4 示例。该外部素材未包含在此仓库和 MIT 许可范围中，也不随公开发行包分发。

本机验收前可运行根目录 prepare-test-media.ps1，或自行从 https://developer.mozilla.org/shared-assets/videos/flower.mp4 下载到 test-assets/flower.mp4。下载只发生在明确执行开发辅助脚本时，日记程序本身不会下载或上传背景。

MDN 文档：https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video 。素材使用以其来源提供的条款为准。花朵视频由 .gitignore 排除，不应提交。
