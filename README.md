# DiaryCard · V2.1.1 双模式版

公开版本 V2.1.1，程序内部版本 2.1.1。面向使用 Obsidian 和独立写日记的 Windows 用户。Windows x64 自包含，完整解压后双击运行，无需另装 .NET；首次启动提供设置向导。

从 [V2.1.1 Release](https://github.com/Oliver-Yang9/DiaryCard/releases/tag/V2.1.1) 下载 Windows-x64.zip。便携程序建议放在有写入权限的新目录；使用同一日记库前请先退出旧卡片。

## 首次使用

双击 日记卡片.exe，明确选择一种方式：

- 使用 Obsidian：沿用 V2.02 设置，读取已有 Daily Notes / Periodic Notes 的模板、位置和命名；也可新建 DailyNote 标准库。
- 独立使用 DiaryCard：无需安装 Obsidian。在软件目录的 Diary 或自选空文件夹创建独立资料夹，日记、任务、模板和周报都能在软件内使用；也可重新载入已有 DiaryCard 资料夹。

取消不会初始化日记或默认数据，陌生非空文件夹不会被覆盖。两种模式不自动搬运旧日记，切换后只对当前选择的位置读写。

首次设置页可以选择“登录 Windows 后自动打开卡片”，默认关闭。后续也可在“••• → 开机自启动…”开启或关闭，再点击“保存设置”。软件不会替用户默认开启。

## 日常操作

- 在桌面卡片填写当天内容；支持中文、多行、任务复选框、Markdown 栏目编辑。
- 拖动顶部移动，拖动四边或右下角缩放；顶部提供隐藏至托盘、置顶、保存后退出。
- 托盘单击或再次启动恢复；Ctrl+S 保存；Esc 隐藏。
- 贴边收起和展开保持平滑动画，时长分别约 400 / 360 毫秒。系统关闭动画或不支持桌面合成时采用回退显示。
- 主题库提供清透、暖纸、深色、磨砂主题，支持本地图片、GIF、静音 MP4 和透明度调整。
- 输入停顿自动保存；失败保留输入；启动、恢复及跨天时读取或匹配当天内容。

## 内置资料库

“••• → 日记资料库…”可以：

1. 按日期或中文正文搜索历史日记。
2. 编辑已有历史日记、任务勾选和栏目原文。
3. 阅读周报并点击来源跳转；编辑自动区之外的手工补充。
4. 选择“模板”，直接修改 Markdown，或用“添加栏目”增加二级标题；保存后主卡片自动同步。
5. 导出 Markdown 副本；保存冲突时保留草稿再重新读取。

当天日记回到主卡片填写，避免两个可写界面互相覆盖。历史编辑未保存或有冲突时，退出、切换资料位置和周报生成都会先要求处理。

阅读器支持日记表单、常见标题和来源链接；不提供 Obsidian 插件或完整复杂 Markdown 渲染功能。

## 周报

入口“••• → 周报汇总…”。每期按周六至下周五的 7 天日记原文分类摘编，按截止周五的 ISO 周命名。保留计划、待办和已完成状态，去重并附本地来源。

可选周一至周日、00:00—24:00 的生成时间，精确到分钟，采用北京时间 UTC+8。24:00 即次日 00:00。自动生成默认关闭；开启后仅卡片运行（含托盘隐藏）时检查，退出期间错过的在下次打开补跑最近一期。

已有周报只更新唯一 AUTO 自动区，保护手工补充；标记异常另存待合并。详见 docs/weekly-report.md。未新增跨天任务继承，模板原有提示不代表程序实现了该功能。

## 修改方式和保存位置

- “••• → 使用模式…”在两种模式间选择。
- “••• → 日记库设置…”修改当前模式的位置、模板与保存规则。独立模式显示资料夹设置，Obsidian 模式沿用 V2.02。
- 更改前保存主卡片与资料库输入，成功后自动重新打开；旧文件留在原处，目标已有内容保留。
- 主题和背景等偏好保留，周报设置按位置隔离。
- 如果命中旧 PathMappings 地址映射，会提示改选实际地址，避免预览和写入位置不同。

## 开机自启动

两版共用当前 Windows 用户的一个启动入口。开启当前版本会切换本软件的入口至当前 EXE 和配置；关闭当前版本不会删除其他版本或位置的入口。无需管理员权限。

移动、改名或删除程序后，旧入口不会自动找到新位置；请手动打开新位置，在设置中重新开启。Windows 的启动应用管理或系统策略仍可禁用该入口。本次测试没有开启真实启动项，也未实际重启电脑验收。

## 本地数据与迁移

独立模式的 Diary/ 内有 日记/、模板/、周报/ 及 diarycard-library.json，不创建或读取 .obsidian。正文仍是本地 Markdown，便于备份和导出。

EXE 旁 diary-card.json 保存模式和位置；data/ 保存外观、背景副本、恢复草稿、备份及周报设置。迁移便携程序时应保留配置、data 和自己的资料夹。更改保存位置不会自动移动旧文件。

旧 V2.02 配置不含 StorageMode 时继续按 Obsidian 使用；显式选择 standalone 才进入独立模式。

## 构建与验证

源码在 src/，需 .NET 10 SDK：

~~~powershell
.\build.ps1
.\verify-review.ps1 -ExePath .\build\local-review\日记卡片.exe
~~~

build.ps1 默认输出 build/local-review，可传 -DotnetPath、-OutputDirectory。首次还原可能访问 NuGet 官方源；日常使用不联网。

测试写操作均在 local/tests/ 隔离目录；真实模板只读。启动设置测试使用内存替身和不生效的隔离注册表测试键，不改真实开机启动入口。源码包不含私人日记、配置、草稿或测试资料。

## 已知边界

程序未带 Authenticode 签名。只在本机 Windows 环境实际验证，尚未在全新且未安装 Obsidian 的机器上单独验证；独立流程代码和测试不调用 Obsidian 或外部编辑器。物理断电、所有输入法、多显示器缩放组合未全面覆盖。

文件符号链接专项测试因当前账号无创建链接权限而跳过，不计为通过。实现中仍会检查重解析路径。
